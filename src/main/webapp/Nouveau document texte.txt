🔑 Points de sécurité critiques

Point Méthode
Token API Ne jamais hardcoder → variables d'environnement
Webhook Vérifier signature HMAC + whitelist IP
Référence Unique, non devinable (UUID + timestamp)
Accès cours Vérifier paiement SUCCESS avant de débloquer
Rate limiting Max 5 tentatives/heure par utilisateur
Logs Ne jamais logguer token ou infos bancaires
HTTPS Obligatoire en production
Session Vérifier que l'utilisateur connecté = acheteur

---

✅ Validation avant passage en production

· Tous les endpoints sont en HTTPS
· Le webhook est accessible publiquement
· La signature HMAC est validée côté backend
· Les IP de PawaPay sont en whitelist
· Les montants sont validés (pas de paiement à 0 ou négatif)
· Les références sont uniques
· Rate limiting actif
· Logs sécurisés sans données sensibles
· Testé avec sandbox PawaPay
· Scripts SQL versionnés
· Rollback possible en cas d'échec

-- Table des paiements
CREATE TABLE IF NOT EXISTS payments (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    course_id INT NOT NULL,
    reference VARCHAR(100) UNIQUE NOT NULL,
    transaction_id VARCHAR(100),
    amount DECIMAL(10,2) NOT NULL,
    currency VARCHAR(3) DEFAULT 'USD',
    phone_number VARCHAR(20),
    status VARCHAR(20) DEFAULT 'PENDING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id),
    INDEX idx_course_id (course_id),
    INDEX idx_reference (reference),
    INDEX idx_status (status),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (course_id) REFERENCES cours(id) ON DELETE CASCADE
);

-- Table des accès aux cours
CREATE TABLE IF NOT EXISTS user_course_access (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    course_id INT NOT NULL,
    granted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    expires_at TIMESTAMP NULL,
    INDEX idx_user_course (user_id, course_id),
    UNIQUE KEY uk_user_course (user_id, course_id),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (course_id) REFERENCES cours(id) ON DELETE CASCADE
);
